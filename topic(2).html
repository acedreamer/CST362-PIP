Module 2 2D/3D Transformations

❖ Strategy for Mod 2

Golden Overlap: 2D Composite Transformation problems appear on BOTH sides consistently. Mathematical proofs for additive/multiplicative properties appear prominently on the Even side. Polygon filling (Boundary/Scan-line) spans both.
Recommendation: Do NOT skip Polygon Filling algorithms. If you are good at Matrix Multiplications, you can score easily here.

2D Composite Transformations (Problems) SURE SHOT (4/4)
↓
Part B (14m) Golden Overlap

Prep Note: These problems usually involve applying multiple transforms (Translate, Scale, Rotate) sequentially to a set of points (Line or Triangle). Use Homogeneous coordinates (3x3 matrices).

Key Matrices
Translation: [1 0 tx; 0 1 ty; 0 0 1]. Rotation: [cos -sin 0; sin cos 0; 0 0 1]. Scaling: [sx 0 0; 0 sy 0; 0 0 1].
⚠️ Typical Flow
Translate to origin -> Rotate/Scale -> Translate back. E.g. Rotate square by 45deg about its vertex (2,6) [May '23].

Proofs: Additive/Multiplicative Properties HIGH PROB (3/4)
↓
Part B (7m) Even Slot (Q14)

Prep Note: You must mathematically prove that two successive rotations are additive: R(θ1) * R(θ2) = R(θ1 + θ2). Same for scaling being multiplicative and translations being additive.

How to execute
Write the 3x3 matrices. Perform matrix multiplication. Use trig identities: cos(a+b) = cos(a)cos(b) - sin(a)sin(b) to simplify the rotation matrix proof.
